title: はじめに
---

rssstv は、アマチュア無線の SSTV(Slow Scan Television)を送受信するデスクトップ
アプリケーションです。無線機の音声を取り込んで画像を復調し、テンプレートを重ねた
画像を送信します。

このマニュアルはアプリケーションの操作を説明します。プロトコルや実装の詳細は
対象外です。

## アーカイブに入っているもの

| 名前 | 内容 |
| --- | --- |
| `rssstv` | 本体。このマニュアルが説明するアプリケーション |
| `encode-wav` | テンプレートを重ねた画像を SSTV の WAV に書き出すコマンド |
| `decode-wav` | SSTV の WAV から画像を復元するコマンド |
| `templates/` | MMSSTV 付属の 5 つのテンプレートを KDL 形式に移植したもの |
| `help/` | このマニュアル |
| `licenses.html` | 依存ライブラリのライセンス一覧 |
| `LICENSE` | 本体のライセンス |

`encode-wav` と `decode-wav` はコマンドラインツールです。使い方は同梱の
`README.md` を参照してください。

## 起動する

アーカイブを展開して `rssstv` を実行します。インストーラーはありません。展開先は
どこでも構いませんが、設定や画像は実行ファイルの隣ではなく OS のユーザー
ディレクトリに置かれます([ファイルの場所](files.md))。

同時に動かせるのは 1 つだけです。オーディオデバイスを掴んだままになるため、
2 つ目を起動すると、起動済みのウィンドウを前に出して終了します。

実行ファイルには署名がありません。macOS ではダウンロードした
アーカイブに検疫属性が付くので、最初の 1 回だけ外してください。

```text
xattr -dr com.apple.quarantine rssstv
```

Linux でタスクスイッチャーやドックにアイコンを出すには、同梱の
`assets/rssstv.desktop` と `assets/icon.png` をインストールします。手順は
`README.md` にあります。

## 最初にすること

1. **設定 › 自局情報…** でコールサインを入力します。送信にはコールサインが必要で、
   入っていないと TX ボタンが押せません。運用地とグリッドはテンプレートから
   参照するためのもので、必須ではありません。
2. **設定 › 入力デバイス** で、無線機の音声が入っているデバイスを選びます。選んだ
   時点で受信が始まります。
3. 送信するなら **設定 › 出力デバイス** で、無線機に音声を送るデバイスを選びます。

選んだデバイスと自局情報は設定ファイルに保存され、次回の起動でも使われます。

表示言語は **設定 › 言語** で切り替えます。初回は OS の言語に合わせて選ばれます。

## 画面の見かた

ウィンドウは、左に画像、右に操作パネルという構成です。

- **受信 / 送信タブ** — パネル上部で切り替えます。タブを切り替えても受信は
  止まりません。受信中に送信タブを見ても画像は失われません。
- **画像** — 受信タブでは復調中の画像、送信タブでは送信する画像そのものが
  出ます。画像の下の行に、モード・サイズと今何をしているかが出ます。
- **レベルバー** — 受信タブでは入力レベル、送信タブでは送信レベルです。
- **モード** — 自動判定(VIS)の切り替えと、モードのドロップダウン。
- **リグ** — `rigctld` への接続とバンド操作([リグコントロール](rig.md))。
- **QSO** — 相手局のコール、RSV/NR、受信 RSV。テンプレートから参照されます。
- **テンプレート / ストック画像** — 送信画像の材料([送信](transmit.md))。
- **最下段** — 左にエラー、右にサンプリング周波数と復号したコールサイン。

画像の表示倍率は **表示 › 拡大 / 縮小 / 等倍に戻す** で変えられます。
