---
title: リグコントロール
---

無線機の PTT を制御し、周波数を読み、バンドを移動します。無線機とのやりとりは
すべて Hamlib の `rigctld` を経由します。無線機を直接叩くコードは入っていません。

リグコントロールを使わなくても送受信はできます。PTT を手動や VOX で操作している
なら、この章は読み飛ばして構いません。

## `rigctld` を先に起動する

`rigctld` はこのアプリケーションには含まれておらず、自動でも起動しません。
Hamlib を導入して、自分の無線機に合わせて起動しておいてください。

```text
rigctld -m 1035 -r COM3 -s 38400
```

`-m` のモデル番号は `rigctl -l` で調べられます。

シリアルポートを掴むのは `rigctld` だけなので、ロギングソフトなど他のプログラムも
同じ無線機を同時に使えます。WSJT-X の `Hamlib NET rigctl` と同じ構成です。

## 接続する

**リグ** パネルの **接続** ボタンで接続します。状態はボタンの隣に出ます。

| 表示 | 意味 |
| --- | --- |
| 未接続 | 接続していません |
| 接続中… | 接続処理中です |
| 接続済み | 接続でき、受信状態です |
| 送信中 | 送信のために PTT が入っています |
| 接続失敗 | 接続できませんでした。**接続し直す** で再試行します |

接続すると、無線機の周波数を定期的に読んでパネルに表示します。読めた周波数は
テンプレートの `${radio.frequency}` と `${radio.band}` にも入ります。

接続先の既定は `127.0.0.1:4532` です。別のアドレスやポートを使う場合、複数の
`rigctld`(無線機とアンプなど)を使う場合は `config.toml` の `[rig.ports]` に
書きます。

## バンド操作

リグパネルのドロップダウンでバンドを選ぶと、そのバンドに移動します。左右のボタンは
バンド内で周波数を上下させます。周波数がどのバンドにも当てはまらないときは
「バンド外」と出ます。

バンドの一覧は `bands.toml` から読みます。ファイルがなければアプリケーション内蔵の
バンドプランが使われるので、日本の一般的な運用ならそのままで動きます。

## 送信との関係

送信するとき、アプリケーションは次の順で動きます。

1. スクリプトの `transmit` を呼び、無線機を送信状態にする。
2. 無線機が切り替わったことを確認してから音声を流し始める。
3. 音声を出し終えたら `receive` を呼び、受信に戻す。

キーイングに失敗した場合、送信は中止されます。受信状態の無線機に音声を流し込んで
しまうことはありません。

リグコントロールが有効でまだ準備できていない間は TX が押せません。ボタンに
カーソルを合わせると理由が出ます。

## 動作を変える

何を送るかは Lua スクリプト `rigcontrol.lua` が決めます。データモードへの切り替え、
モニターレベル、帯域幅、アンプの操作など、局ごとに違うものはここに書きます。

スクリプトもバンドプランもアプリケーションに内蔵されていて、ファイルがなくても
そのまま動きます。自分で書き換えるときは、**設定 › リグコントロール** から
**デフォルトスクリプトを書き出す** または **デフォルトバンドプランを書き出す** を
実行してください。`config.toml` と同じフォルダーに `rigcontrol.lua` と
`bands.toml` が作られます。編集はお使いのテキストエディタで行ってください。

書き出しただけでは読み込み直されません。編集中のファイルを途中で読むことがない
ようにするためで、変更は次回の起動から有効になります。

スクリプトとバンドプランの詳しい書きかたは、リポジトリの
`docs/memo/rssstv/rig-control.md` にあります。
