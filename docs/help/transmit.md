---
title: 送信
---

送信タブに出ている画像が、そのまま送信される画像です。確定用の別プレビューは
ありません。テンプレートやストック画像を選び直すと、その場で送信画像が変わります。

## 送信までの手順

1. **設定 › 自局情報…** でコールサインを入れます(未入力だと送信できません)。
2. **設定 › 出力デバイス** で、無線機に音声を送るデバイスを選びます。
3. 送信タブで、**テンプレート** 一覧からテンプレートを、**ストック画像** 一覧から
   背景画像を選びます。
4. **モード** のドロップダウンで送信モードを選びます。送信タブでは自動判定は
   使われません(表示は残りますが無効です)。
5. **送信レベル** のバーをドラッグして出力を合わせます。
6. **TX** を押します。

TX ボタンは、条件が揃っていないと押せません。押せないときはボタンにカーソルを
合わせると理由が出ます。理由は「送信画像がまだ合成されていない」「出力デバイスが
未選択」「自局コールが不正」「リグが未準備」のいずれかです。

送信を止めるときは同じボタン(**TX停止**)を押します。

## テンプレートとストック画像

- **テンプレート** — 送信画像に重ねるレイアウトです。`templates` フォルダーに直接
  置いた `.kdl` ファイルが一覧に出ます。
- **ストック画像** — 背景写真です。`Stocks` フォルダーに直接置いた画像のうち、
  読める形式のものが一覧に出ます。

どちらの一覧にも **再読み込み** と **フォルダーを開く** があります。アプリケーションを
起動したままファイルを足した場合は再読み込みしてください。

背景はモードの寸法を覆うように拡大縮小され、中央で切り出されます。

同梱の `templates/` に、MMSSTV 付属の 5 つを移植したものが入っています。使いたい
ものをテンプレートフォルダーにコピーしてください。各ファイルには、元のテンプレートが
やっていてこの形式では表現できない点がコメントで書いてあります。

## テンプレートから参照される値

テンプレートは `${...}` で値を差し込みます。値の出どころは次のとおりです。

| 出どころ | 例 |
| --- | --- |
| 自局情報ダイアログ | `${station.callsign}`、運用地、グリッド |
| QSO パネル | `${contact.callsign}` ほか、送信 RSV とナンバー、受信 RSV/NR |
| リグコントロール | `${radio.frequency}`、`${radio.band}` |
| 送信時の時計 | `${tx.timestamp.utc}`、`${tx.timestamp.local}` |
| テンプレート変数ダイアログ | `${custom.名前}` |
| 直前の受信画像 | `rximage` レイヤー |

**設定 › テンプレート変数…** は、アプリケーションが知りようのない値を運用者が
自分で決めるための欄です。名前と値の両方を入力します。`${...}` に書けない名前は
印が付いてダイアログに残り、その状態では合成に使われません。

QSO パネルを編集すると送信画像は自動的に作り直されます。時刻を印字する
テンプレートは、分が変わったタイミングでも作り直されます。

## QSO パネル

上から順に、交信している相手局のコールサイン(**DX CALL**)、相手局から受け取った
レポート(**RSV/NR (R)**)、こちらが送るレポート(**RSV/NR (S)**)です。

**RSV/NR (S)** は 2 つの欄に分かれています。左がレポート(既定は `595`)、
右がシリアルナンバー(既定は `001`)です。

その下の **NR Incr.** でシリアルナンバーを 1 つ進め、**NR Reset** で `001` に
戻します。3 桁になるようゼロ詰めしますが、`999` の次は `1000` です。数値でない
交換ナンバーを入れているときは **NR Incr.** は何もしません。シリアルナンバーは
設定ファイルに保存されるので、アプリケーションを起動し直しても続きから使えます。

## 送信中の動作

TX を押すと、リーダー、VIS、画像本体、フッター、FSKID、後続の無音までを一続きで
送出します。画像の下の行に進行状況が出ます。

送信中は、始めた時点の画像を送り続けます。画面上の画像も固定され、テンプレートと
ストック画像の一覧は操作できなくなります。QSO 欄の編集などによる再合成は送信が
終わってから行われます。画面に出ているものが、送っているものです。

**設定 › 送信 › FSKID を送出** で、送信の最後にコールサインを FSK で付けるか
どうかを切り替えます。これを切っていても自局コールサインは必須です。

## 送信レベル

送信レベルはバーそのものをドラッグして決めます。つまみはありません。カーソルを
合わせるとパーセントとデシベルで読めます。送信中はバーが赤く塗られます。

バーの位置は振幅と比例しません。中央でおよそフルスケールの 1/4(約 −12 dB)に
なるように配ってあり、ミキサーのフェーダーの感覚に近くなっています。

無線機の ALC が振れない範囲に収めてください。SSTV は音声そのものが画像なので、
過大入力による歪みはそのまま画質に出ます。

## 対応モード

送信できるのは Robot 36/72、Scottie 1/2/DX、Martin 1/2、PD50/90/120/160/180/240/290
です。ドロップダウンには送信に対応しているモードだけが出ます。
