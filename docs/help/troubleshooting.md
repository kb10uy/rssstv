title: 困ったとき
---

## デバイスが一覧に出ない

**設定 › 入力デバイス** と **出力デバイス** の一覧は、起動時とデバイスが変化した
ときに作られます。USB オーディオを後から挿した場合は、一度メニューを開き直して
ください。

名前が同じデバイスが複数あるときは、`sof-hda-dsp (hw:CARD=0,DEV=6)` のように
システム側の識別子が併記されます。それでも区別できない場合は番号が付きます。

## 「オーディオデバイスが停止しました」と出た

デバイスが取り外されたか、電源が切れたか、ストリームを開き直す必要がある状態です。
受信は止まっています。ダイアログの **再試行** を押すか、設定メニューから別の
デバイスを選んでください。

## 受信が始まらない

- 入力デバイスは選んでいますか。選ぶまで受信は始まりません。
- 画面下部に音声デバイスのサンプリング周波数が出ていますか。出ていなければ、
  デバイスが開けていません。
- 音が届いているかどうかは、このアプリからは分かりません。OS 側のミキサーで
  そのデバイスの入力が有効か、音量が 0 でないかを確認してください。
- 自動判定を切っている場合、ドロップダウンで選んだモード以外は受信しません。
  分からないときは自動判定を入れてください。

## 画像が斜めになる

**傾き補正** を有効にしてください。既定で有効です。

受信が始まってから有効にした場合、その受信には効きません。次の受信から効きます。

補正後のまっすぐな画像が出るのは、画像が最後まで埋まってから 1 秒ほど後です。
すぐに切り替わらなくても待ってください。

## 画像が途中で切れる

信号が途切れた、または同期を失った場合、そこまでの画像を残して信号待ちに戻ります。
異常ではありません。

このとき保存されるのは、行の 65% 以上が復調できていたものだけです。それ未満だと
画面には残りますがファイルにはなりません。

## 「サンプル欠落」が出る

入力の取りこぼしです。音声の連続性が壊れるので、その時点で復調をやり直します。
時々出る程度なら実害は小さいですが、頻発する場合は次を確認してください。

- 他の重い処理が同じマシンで動いていないか。
- オーディオデバイスのバッファサイズが極端に小さくないか。
- 省電力設定で CPU の周波数が絞られていないか。

## TX が押せない

条件が揃っていません。ボタンにカーソルを合わせると理由が出ます。

| 理由 | 対処 |
| --- | --- |
| 送信画像がまだ合成されていません | テンプレートとストック画像を選び、合成が終わるまで待つ |
| 出力デバイスを選択してください | **設定 › 出力デバイス** で選ぶ |
| 自局コールが不正です | **設定 › 自局情報…** でコールサインを入れ直す |
| リグが未準備 | リグパネルで接続するか、リグコントロールを使わない設定にする |
| トーン送信中です | 隣の **1750** ボタンを押してトーンを止める |

コールサインは、FSKID を送らない設定であっても必須です。送信している局を名乗る
唯一の情報だからです。

## 送信した音が歪む

**送信レベル** のバーを下げてください。バーにカーソルを合わせるとパーセントと
デシベルで読めます。無線機の ALC が振れない範囲に収めます。SSTV は音声の形が
そのまま画像なので、歪みは相手局の画質にそのまま出ます。

## `rigctld` に接続できない

- `rigctld` を自分で起動しましたか。アプリケーションは起動しません。
- アドレスは既定で `127.0.0.1:4532` です。別のポートで起動している場合は
  `config.toml` の `[rig.ports]` に書いてください。
- **接続し直す** で再試行できます。

## テンプレートやストック画像が一覧に出ない

- テンプレートは `templates` フォルダーの直下に置いた `.kdl` ファイルだけが
  対象です。下位フォルダーは見ません。
- ストック画像は `Stocks` の直下に置いた、読める形式の画像だけが対象です。
- アプリケーションを起動したまま追加した場合は、一覧の **再読み込み** を
  押してください。

置き場所は[ファイルの場所](files.md)にあります。

## 2 つ目のウィンドウが開かない

仕様です。オーディオデバイスを掴んだままになるため、同時に動かせるのは 1 つ
だけです。2 つ目を起動すると、起動済みのウィンドウを前に出して終了します。

## macOS で起動できない

ダウンロードしたアーカイブに検疫属性が付いています。実行ファイルは署名されて
いないので、最初の 1 回だけ属性を外してください。

```text
xattr -dr com.apple.quarantine rssstv
```

## Linux でアイコンが出ない

Wayland ではアプリケーション側からアイコンを渡せません。同梱の
`assets/rssstv.desktop` と `assets/icon.png` をインストールすると、
コンポジタがそこからアイコンを見つけます。手順は `README.md` にあります。

## それでも解決しない

ログファイルを添えて報告してください。置き場所は[ファイルの場所](files.md)の
「ログ」にあります。
